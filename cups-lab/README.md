# Лабораторный стенд: уязвимости CUPS (CVE-2024-47076/47175/47176/47177)

Контейнер Ubuntu 24.04 с **умышленно устаревшими (уязвимыми)** версиями
CUPS для учебной демонстрации обнаружения и устранения цепочки уязвимостей.

> ⚠️ Стенд только для изолированной учебной среды. Порт 631 наружу не
> публикуется. Эксплойт-код в стенде отсутствует - только средства
> обнаружения и устранения.

## Требования
- Docker + Docker Compose (Docker Desktop на Windows/macOS или Docker на Linux).

## Запуск
```bash
cd cups-lab
docker compose up --build -d
docker compose exec cups-lab bash
```

## Внутри контейнера
```bash
check_vuln.sh     # показать уязвимое состояние (версии, порт, конфиг)
fix_vuln.sh       # применить исправления (обновление, отключение, фаервол)
check_vuln.sh     # убедиться, что всё закрыто
```

## Остановка и удаление
```bash
docker compose down
```

## Что демонстрируется
1. Установлены старые версии cups-browsed / cups-filters / libcupsfilters / libppd.
2. Сервис cups-browsed слушает UDP/631 и принимает удалённые анонсы.
3. После `fix_vuln.sh`: пакеты обновлены, cups-browsed остановлен,
   BrowseRemoteProtocols=none, UDP/631 закрыт.
