# Лабораторный стенд: Dirty Pipe (CVE-2022-0847)

ВМ с **уязвимым ядром Linux** (Ubuntu 21.10, ядро 5.13.x) для учебной
демонстрации обнаружения и устранения уязвимости повышения привилегий
Dirty Pipe.

> Контейнеры Docker **не подходят** для этой уязвимости: они разделяют
> ядро хоста. Поэтому используется отдельная виртуальная машина (Vagrant +
> VirtualBox) с собственным уязвимым ядром.

## Требования
- VirtualBox
- Vagrant

## Запуск
```bash
cd dirtypipe-lab
vagrant up
vagrant ssh
```

## Внутри ВМ
```bash
check_dirtypipe.sh                 # проверка текущего ядра
check_dirtypipe.sh 5.10.102 5.16.10 5.16.11   # тест на примерах версий
sudo fix_dirtypipe.sh              # обновление ядра
sudo reboot                        # перезагрузка
# после входа заново:
check_dirtypipe.sh                 # убедиться, что ядро исправлено
```

## Остановка и удаление
```bash
vagrant halt       # выключить
vagrant destroy    # удалить ВМ
```

## Примечание
Если box `ubuntu/impish64` недоступен, подойдёт любой образ с ядром из
диапазона 5.8-5.16.10 (например, более старые сборки Ubuntu 20.04/21.04
или Debian 11 без обновлений). Исправленными считаются ядра
>= 5.10.102 / 5.15.25 / 5.16.11.
